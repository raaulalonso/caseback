# Rules for agents working in this repository

For Claude Code, Codex, Cursor, Copilot and any other coding agent. People can read it too. `CLAUDE.md` imports this file.
`web/AGENTS.md` adds a rule for the Next.js site and applies inside `web/`.

Caseback is a 25 mm biometric disc that sticks under a watch caseback. This repository holds how it is built: hardware
files, firmware, the iOS app, the protocol, the algorithms and the website.

## Do not commit or push on your own

Commit or push only when the person who owns the working tree asks for it in that session. Never force-push, never
rewrite history and never delete a branch or a tag unless they ask for exactly that.

## This repository is public

Do not add:

- Absolute paths of a machine (a home folder or a temporary folder on macOS, Linux or Windows), also inside generated files and archives.
- Personal email addresses, keys, tokens, passwords, certificates, provisioning profiles or `.env` files.
- Screenshots or renders that show a signed-in account, a notification or a mailbox. Take app captures from a clean simulator.
- Files that are not ours and have no licence that lets us publish them: datasheets, vendor 3D models, photos from the web.
- Generated output and local tool state: whatever `.gitignore` lists, `node_modules`, `DerivedData`, `*.xcodeproj`
  (generated by `xcodegen`), `*.blend1`.

## Working

- Build and run the tests that touch what you changed. Commands per area are in `CONTRIBUTING.md` and `.github/workflows/ci.yml`.
  A change to the wire format updates the spec, the three implementations and the golden fixtures together.
- Do not tune anything against a TEST split and do not run a TEST evaluation again once it has been looked at. Never compare
  with commercial devices.
- Write plainly, in English or Spanish as the file already is: concrete facts, no slogans, no "not X but Y", no staccato
  fragments, no groups of three adjectives for rhythm.
- Do not place orders, pay for anything or send a job to a printer or a device on someone's behalf.
- Say what you ran and what it printed. Do not say something was verified when it was not.

## Commits

- Small commits, one topic each, with a subject in the style of the history: an area, a colon and what changed
  (`web:`, `hardware:`, `firmware:`, `ci:`).
- Agent commits end with a trailer that names the agent: `Co-Authored-By: <agent name> <the noreply address its vendor gives>`.
  Do not add a `Signed-off-by` for the owner: that is their statement under the DCO.
- Run `git status` before `git add -A`, or add paths by name.
